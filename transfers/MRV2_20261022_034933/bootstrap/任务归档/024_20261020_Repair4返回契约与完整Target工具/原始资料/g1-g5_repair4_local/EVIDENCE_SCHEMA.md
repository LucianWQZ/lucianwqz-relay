# Evidence layers
The authoritative executable schemas/checkers are committed tools/p7x_graph_repair4_acceptance.py, fixture.py, target.py and campaign.py. Do not hand edit result identities.

Campaign producer: Repair2 schema with run/case/attempt/source/process/engine identity, actual inventory, snapshot, outputs and original exception. New optional output fields are status/reason+nullable hash. B0 acceptance additionally requires actual three replay buckets, every real layer update, unique generations, retirement, outputs and normal status; missing numeric hashes remain OPEN.

C2 producer: p7x-repair4-fia-fixture-v1 + independent manifest. Includes runtime API sources/hash, actual buffers, full table, generation/epoch, descriptor/layer, output, completion, every case and abort. Host synthetic test documents are never device reports.

G4F producer: p7x-repair4-full-forward-v1 .pt loaded weights_only, complete selected blocks and actual full-forward outputs. Natural observation is not a controlled pair. Missing/unaligned/omitted evidence remains OPEN. Exact physical IDs currently required; distinct allocations need a later explicit normalization contract.

EVIDENCE_INTEGRITY / HOST_CONTRACTS / DEVICE_FUNCTIONAL_GATES / DEVICE_EVIDENCE_LEVELS / NUMERIC_GATES are separate. A checksum or checker PASS never upgrades an absent lower-level device fact.
